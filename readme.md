#  Simple Food Delivery Web App

This is a basic food delivery web application built using **HTML**, **CSS**, and **JavaScript** (no frameworks or backend). It mimics the core flow of Swiggy-style ordering.

---

##  Features

- View food items with image, price, and rating
- Add food to cart
- View cart items with total cost
- Remove specific items from the cart
- Cart data is stored in `sessionStorage` (resets on refresh)
- Place order via:
  - Cash on Delivery
  - Online Payment
    - Google Pay / PhonePe
    - QR code shown if Google Pay selected
- Final order confirmation message displayed

---

##  Pages Included

- `index.html` – Main page displaying food items
- `cart.html` – Cart page showing selected items and total price
- `order.html` – Order form with address, phone, and payment mode

---

## How to Run

1. Clone the repository or download the ZIP
2. Open `index.html` in your browser
3. Add items to cart → go to Cart → click **Order Out**
4. Complete the order in `order.html`

---

##  Note

- This project does **not** use a database or server
- Cart is stored using `sessionStorage` and is cleared on placing the order or page refresh
- You can replace QR code images with your own or real payment links

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
